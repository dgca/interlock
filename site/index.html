Repeatable workflows for AI agents

Interlock follows the steps you define. It runs the code, gives your agent the steps that need judgment, and checks results against your rules. Your agent can build and run workflows through Interlock’s local MCP server.

    How this demo works

    1. 1. Build the stat sheet

      Fetch looks up the Pokémon. A script pulls out its height, weight, and base stats.

    2. 2. Hand off to an agent

      Small Pokémon take the branch that asks for a mascot pitch.

    3. 3. Submit a reply

      Claim the assignment to try the sample reply or write your own.

    4. 4. Check and save the result

      Interlock flags missing fields so you can fix the reply and submit again.

    This browser demo uses PokéAPI data and sample agent replies.

    Install Interlock

    Requires Node.js 24.13 or later on macOS or Linux.

    npm install -g @type_of/interlock
interlock

    Open 127.0.0.1:4310. Use Connect with MCP in the sidebar to connect your agent, or open Workflows → Import → Starters to browse example workflows.

    Build your workflow

    Tell your agent what the workflow should do. Over MCP, it can create a draft or update one you already have. Open the same draft in the visual editor to adjust the graph or edit its JSON.

    Set input and output contracts so Interlock can check what each step receives and returns.

    Inspect your runs

    Open Runs to follow a live execution or revisit a past one. The graph shows which path the run took and where it's waiting. Select a step to see its inputs, outputs, or errors.

    For a Batch, drill into any item. If the Batch fails, retry it from the inspector and keep the items that already succeeded.

    Bring your own agent

    Connect your agent over MCP. When a run needs an agent, copy its instructions into your conversation so the agent can claim and complete the assignment.

    For automatic execution, configure Claude Code, Codex, or Pi in Harnesses and select it in the workflow's settings. Interlock can then launch a session when an assignment is ready.
