Repeatable workflows
for AI agents.

Define the steps. Interlock runs the code, gives agents the work that needs judgment, and checks the results. Build and run workflows in the editor or through MCP.

Install Interlock

Requires Node.js 24.13 or later on macOS or Linux.

Terminal 
npm install -g @type_of/interlock
interlock

Open 127.0.0.1:4310. Use Connect with MCP in the sidebar to connect your agent, or open Workflows → Import → Starters to browse example workflows.

Build your workflow

Define the steps you want to follow. Run code, assign work to agents, and branch based on the results. Combine smaller workflows into larger ones to reuse common steps and keep complex processes manageable.

Build in the editor, or ask your agent to create workflows through the built-in MCP server.

Run on demand or autonomously

Start a workflow yourself, set a schedule, or trigger it when another workflow completes or fails. Workflows can run unattended and wait for your input when a step needs an answer or approval.

Inspect your runs

See each step’s inputs, outputs, and errors. Track run duration and waiting time, along with reported model usage and cost.

Free, local,
and open source

Interlock runs on your machine. Your workflows and run history are stored locally, under your control.
