Agent work you can run twice.

Interlock is a local workflow engine for AI agents. Draw the procedure once: it runs the code steps itself, hands each judgment call to the agent you already use, and checks every answer against a contract. Try a run below. You are the agent.

    Press Run v1. Fetch asks PokéAPI, the Script computes a stat sheet, and the Condition sends small Pokémon to the Agent step. Everything else exits with its stats.

      Two commands, one URL. Then ask your agent.

      The npm package includes the engine, the UI, the CLI and the MCP tools. The engine serves Streamable HTTP MCP at 127.0.0.1:4310/mcp from the same process as the UI. Interlock never calls a model; your harness keeps its own tools, approvals and model. 

      # Node 24.13 or later, macOS or Linux
npm install -g @type_of/interlock
interlock   # then open http://127.0.0.1:4310

      About the replicas. The run inspector, Batch and publish review above are built for this page in Interlock's own styling. The Fetch step calls the public PokéAPI from your browser (with a cached copy for the suggested names if the request fails), the Script runs the starter workflow's code verbatim, and contract errors follow Interlock's wording. Agent answers you "write for me" are templated from the stat sheet, not generated by a model. Timing is slowed for legibility.
