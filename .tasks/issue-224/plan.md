## Build evidence

Implementation follows the planned split. The inline supervisor source is bundled as a string, so packed installations need no TS loader or additional executable. Progress polling runs every 100 ms; live process identity is rechecked at most once per second and before stop. An authenticated stop request during the launch handshake is consumed before the Script starts. A completed historical Script stop is a no-op and cannot cancel later work.
