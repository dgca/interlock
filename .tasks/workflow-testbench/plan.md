The repository already scans small local document collections and exposes ordinary runs through one engine. This plan extends that existing model within explicit bounds; it does not claim distributed scheduling or side-effect-free execution. No unresolved plan decisions remain.

## Implementation refinements

Report pagination also enforces a 256 KiB JSON cap, returning exact totals and continuation offsets when long quality notes shorten a page. Captures are bounded to 64 transitive pins and 64 prompts totaling 1 MiB; preview blocker details cap at 50 with an exact count. These bounds are recorded in spec.md AC4/AC8 and MCP/docs. Core schemas and byte-bound tests enforce the implementation; this refinement does not change the accepted live-comparison scope.
