## Verified repository facts and risks

WorkflowTriggers currently assumes schedules, transfer format 6 carries schedules and variables, and ExternalInputs is a two-phase submit/accept contract. The server uses a host/origin-checked Hono app bound to 127.0.0.1. Generic document storage supports additive collections, and trigger history uses indexed queries. Primary risks are weakening existing local routes, treating unsigned identity/time as trusted, delivering a stale event to a later node visit, duplicate effects after trimming logs and schedule regressions. Each has the direct positive/negative controls above. No product decision remains open.
