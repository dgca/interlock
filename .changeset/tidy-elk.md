Add ELK as an alternative layout for Tidy, with ordered branch handles and nested Batch layouts. The Tidy button runs the last chosen layout in one click; a gear beneath it selects and remembers the mode across workflows and browser sessions. ELK loads on first use, changes only node positions, and supports one-step undo. Pending layouts are discarded when the draft changes or the editor switches away from the canvas.
