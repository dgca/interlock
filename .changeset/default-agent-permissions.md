Add **Default agent permissions** in AI Settings → Execution settings. Managed Agents whose harness and workflow set no level of their own use it, so choosing Full access once covers them all. The first time you enable a harness in the app, Interlock asks how managed agents should run. Harness defaults gain **Use default**, workflow **Agent permissions** shows the resolved level and where it comes from, and execution details report a new `global` permission source. Harnesses saved with the original Standard value follow the default; an explicit Standard chosen now stays Standard. The SDLC and pull request watcher starters no longer set Standard on the workflow, so new imports follow the default; Plan review stays Read only. `executors` settings and `save_settings`, and MCP `manage_executors`, read and write `defaultPermissions`. Nothing changes for an existing install until a default is chosen. A profile save over the API, CLI or MCP that omits `permissions` now means "use default" where it used to store Standard, so a full-replace save of a Read only or Full access harness that leaves the field out follows the default.
