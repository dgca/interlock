Add opt-in workflow memory. Turn it on in a workflow's settings to keep revisioned Markdown notes for the workflow and each Agent step. Agents save notes during a claim with MCP `work_memory`; notes wait for review by default. Live notes join Agent prompts in a marked Memory section within a size budget, and each run captures them at startup. Manage notes with `interlock memory`.
