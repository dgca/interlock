# Changesets

Run `pnpm changeset` for changes that need a release. Select the public root package, `@type_of/interlock`, even when the implementation lives in a private workspace package.

Run `pnpm release:status` to inspect pending changes and `pnpm release:version` to apply them. Publishing is a separate step.

See [Release Interlock](../docs/releases.md) for the full process.
