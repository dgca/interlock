Claude Code and Pi sessions that Interlock launches can save workflow memory notes and call workflow tools. Interlock attaches two tools of its own, `save_memory_note` and `call_workflow_tool`, and handles each call against the claim it holds, so the session never receives a claim token or other credential. Saving is write-only and keeps the usual review, pending limits, prompt budget and escaping. The tools are off at Read only and need no approval at Standard or Full access. That means a managed session at Standard whose step has tool edges now runs those Script and Fetch steps, in its checkout and with arguments it chooses, without a prompt per call: attaching a tool is the workflow author's grant, as it already is for connected agents. Imported Scripts still need their one-time approval. The prompt mentions the tools only when they are attached. Built-in harnesses no longer receive the tool-only credential in their prompt or environment. Execution details record whether the tools were attached.
